# 毛选方法论 Skill 包（maoxuan-skills）

把《毛泽东选集》里可复用的**工作方法**抽成 7 个可安装的 AI Skill，用于调查判断、定优先级、集中资源、推动落地、开好会、诊断顽疾等具体管理场景。

> 本包只提取方法结构，不作政治评价、历史定性与人物评价；不涉及卷六、卷七中已被 1981 年决议否定的具体结论；不替代法律、财务、安全等专业判断。

## 它解决什么问题

面对「事情太多不知先做哪件」「决定发下去没人动」「会议流于形式」「反复整顿无效」这类问题，本包把毛选中经过实践检验的方法拆成可直接调用的能力卡，让 AI 按固定流程引导你把问题拆解到底，而不是给一句笼统的建议。

## 包含内容

| Skill | 解决的问题 | 核心方法 |
|---|---|---|
| `maoxuan` | 路由入口：拿不准用哪个能力时先读它 | 13 张能力卡的意图索引 |
| `maoxuan-investigate` | 信息不全时如何判断、如何知道现场真实情况 | 开调查会、三点抽样（最坏/中等/最好）、亲自记录深访 |
| `maoxuan-priority` | 多目标多要求、资源不够，先做哪一件 | 用「规定性」判据找主要矛盾，收敛为唯一中心工作 |
| `maoxuan-deploy` | 文件发了没人动、试点推不开 | 先突破一点取得具体经验，再以个别指导带一般号召 |
| `maoxuan-team` | 会议流于形式、会上一套会后一套 | 重要问题清单、会前商谈、安民告示、抓紧检查、三七开评定 |
| `maoxuan-concentrate` | 资源远少于对手却想全面推进 | 单点形成三倍以上局部优势，以「全歼」标准定义完成，给放弃清单 |
| `maoxuan-diagnose` | 同类问题多处反复出现、整顿无效 | 看分布判断病灶在人还是在制度，先检查自己的政策 |

主包 `maoxuan/references/` 下另有 13 张完整能力卡（含原文出处、方法论骨架、判停条件）及术语表、速查表、意图索引，供需要原文依据时补读。

## 安装

将 `skills/` 下的目录整体复制到你的 AI 工具 Skill 目录即可，例如：

```bash
# WorkBuddy / Claude Code 等通用 skills 目录
cp -R skills/maoxuan* ~/.workbuddy/skills/
```

子 Skill 可单独安装，也可与主包一起安装。主包内含全部能力卡作为原文与背景补充，子 Skill 是面向具体场景的独立版本。

## 使用示例

直接向 AI 描述你的处境即可，例如：

- 「三个部门同时要我加人，但今年只批了 2 个 headcount，我该先给谁？」→ `maoxuan-priority`
- 「方案发下去两周了，一线还是老样子，怎么推？」→ `maoxuan-deploy`
- 「想搞清楚门店真实的服务问题，但听到的汇报都很好，怎么办？」→ `maoxuan-investigate`

不确定用哪个时，直接问「我这个情况该用哪个方法」，主包会按意图索引路由。

## 目录结构

```
skills/
├── maoxuan/                  # 路由入口 + 13 张能力卡 + 术语表/速查表
│   ├── SKILL.md
│   ├── test-prompts.json
│   └── references/
├── maoxuan-investigate/
├── maoxuan-priority/
├── maoxuan-deploy/
├── maoxuan-team/
├── maoxuan-concentrate/
└── maoxuan-diagnose/
```

每个子 Skill 目录含 `SKILL.md`（能力定义）与 `test-prompts.json`（测试提示词）。
