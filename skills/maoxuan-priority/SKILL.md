# 抓主要矛盾，定唯一中心工作

## R — 原文 (Reading)

> 「任何过程如果有多数矛盾存在的话，其中必定有一种是主要的，起着领导的、决定的作用……因此，研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。」
>
> 「在任何一个地区内，不能同时有许多中心工作，在一定时间内只能有一个中心工作，辅以别的第二位、第三位的工作。」
>
> — 毛泽东，《矛盾论》（1937，第1卷 p197）；《关于领导方法的若干问题》（1943，第3卷 p529）

---

## I — 方法论骨架 (Interpretation)

多数情况下你不是没事做，而是事太多而资源只有一份。平均用力的结果是每件事都做到一半。

这个方法先要求你把矛盾**全部列出来**，然后回答一个特定问题：哪一个是"规定或影响着其他矛盾"的那一个。注意判据是"规定性"，不是"最紧急"、不是"最疼"、也不是"老板最关心"。紧急的事往往是次要矛盾在尖叫。

找到之后还有半句常被忽略：再判断矛盾双方哪一方取得了支配地位，因为"事物的性质，主要地是由取得支配地位的矛盾的主要方面所规定的"。这一步防止你用次要方面去给事情定性——比如一个项目七分成绩三分问题，却被当成"问题项目"处理。

第三件事是把结论落成排序：一定时间内只能有一个中心工作，其余按第二、第三位排。这不是修辞，是防止资源被切碎的操作约束。同时要预设复核点，因为主要矛盾会随力量增减而转移——今天是它，三个月后未必。

## A1 — 应用示例 (Application Example)

### 示例 1: 同一个对手，主要矛盾换了位置
- **类型与来源**: 原书案例（c07；《矛盾论》第1卷 p197 附近）
- **问题/输入**: 中国面对外部压力，需要在多个方向分配有限的抵抗力量。
- **方法论的使用**: 作者对比两次战争：鸦片战争时期与中日战争时期，主要矛盾的对象与性质不同（前者是帝国主义与中国的矛盾以另一种形式展开，后者是民族矛盾上升为主导）。判断依据不是"谁最凶"，而是哪一对矛盾在规定其他矛盾。
- **结论**: 主要矛盾换位后，策略（依靠谁、反对谁、喊什么口号）必须整体换位。
- **结果**: 原书给出判断与随之的策略变化；具体决策过程的争议未展开。

### 示例 2: 西安事变——放掉最直接的敌人
- **类型与来源**: 原书案例（c16；第2卷相关篇章）
- **问题/输入**: 抓住了一个长期敌对阵营的首要人物，群情要求严惩。
- **方法论的使用**: 问"当前规定全局的是哪一对矛盾"——是民族存亡，不是与某一派系的旧账；据此判断该人物的存在与否不影响主要矛盾的解决方向，反而其活着更有利于牵制。
- **结论**: 和平解决，不以复仇为结算方式。
- **结果**: 原书交代了策略与理由；事后各方反应未系统说明。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 同时被三到五件事压住（现金流、核心人员、竞品、合规、家庭），说"都很重要"。
2. 团队每周都在救火，但季度目标一步没动。
3. 资源评审会上各部门都说自己最急，最终按声量分配。
4. 已经抓了一件事，但半年后发现抓错了，因为当初选的是"最疼的"。
5. 需要向上一级解释"为什么这件事排在后面"。

### 语言信号 (用户的话里出现这些就应激活)

- "都很重要，没法排" / "everything is priority"
- "先救火再说" / "firefighting mode"
- "这个最急" / "this is urgent"
- "到底先做哪个" / "what should we do first"
- "资源不够分" / "we're stretched thin"

### 与相邻 skill 的区分

- 与 `maoxuan-investigate` 的区别：调查解决"事实是什么"，本 skill 解决"事实清楚后先做哪件"。事实未清时用调查，不要用优先级排序来掩盖无知。
- 与 `maoxuan-concentrate` 的区别：本 skill 决定"打哪一个"，concentrate 决定"投多少、怎么打完再打下一个"。
- 与普通"四象限/紧急重要矩阵"的区别：本 skill 的判据是"是否规定其他矛盾"，不是"紧急×重要"两个正交轴；且强制输出唯一中心工作与复核点。

## E — 可执行步骤 (Execution)

**必需输入**：① 当前所有在争夺资源的议题清单（≥3 项）；② 每项的资源需求与时间窗；③ 你的总资源约束。
**缺失时询问**：若议题清单来自单一来源（只有老板的话），先要求补入一线与受影响方各一条。

**交付物与完成标准**：一份排序表——第 1 位（中心工作）＋第 2、3 位＋被明确暂停的项；每项附"凭什么排这个位次"的一句话；附主要矛盾的复核时点。

1. **穷举矛盾**
   - 完成标准：列出 ≥3 项互不重叠的议题，每项写成"X 与 Y 之间的张力"（而非"要做 X"）。
2. **判规定性**
   - 完成标准：对每一对议题回答"如果它不解决，另一项还能不能推进"，找出使其他项失去前提的那一个。
   - 判停条件：若两个议题互相规定（互为前提），说明它们其实是同一矛盾的两面，合并后重判。
3. **判主要方面**
   - 完成标准：写出"这件事目前以 X 为主、Y 为次"的定性句，并给出一个可观察依据（比例、趋势、谁在推动）。
   - 数字口径：凡用来支撑判断的量化依据（占比、产能、回收期、缺口），必须给出算式与分母，且能被人当场复算；例："12 人 × 8 个月 = 8 人年，占全年 12 人年的 67%"，而不是"约占三成"。口径不一致（人年 vs 人数、含税 vs 不含税）时先统一再比较。
4. **排中心工作**
   - 完成标准：唯一第 1 位；第 2、3 位明确；其余项写明"暂停/维持"，不留模糊地带。
5. **设复核点**
   - 完成标准：给出复核日期或触发条件（如"现金流转正""关键人到位"），并写明复核时若变化则如何重排。
6. **对外解释**
   - 完成标准：能用三句话向被降级方说明"为什么不是你不重要，而是它不是规定性的那一项"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 事实基础不明时：此时"主要矛盾"只是猜测，应先用 `maoxuan-investigate`。
- 存在必须同时满足的硬约束（法务、安全、合规）时：这些不是"次要矛盾"，而是不可交易的门槛，不能靠排序压掉。
- 危机处置的极短窗口：此时按预案执行，事后再排序。

### 作者在书中警告的失败模式

- **同时有许多"中心工作"**（x12）："在任何一个地区内，不能同时有许多中心工作"——多于一个等于没有。
- **用次要方面定性**（p22 三七开的对应面）：把七分成绩说成问题为主，会导致处置失当。
- **只看最紧迫的**：书中多处指出，最响的矛盾未必是规定性的矛盾（c16 即为反例：最直接的敌人不是主要矛盾的对象）。

### 作者的盲点 / 时代局限

- "规定性"判断在原文中依赖对阶级力量的分析框架，现代组织里需要替换为"依赖关系与前置条件"分析，原文没有给替代工具。
- 作者假定存在一个可被识别的主要矛盾；在高度耦合的系统里，多个矛盾可能互为因果，此时强行排序会掩盖结构性纠缠。遇到这种情况应显式声明"无法单一排序"，而不是硬选一个。
- 主要矛盾的"转化"在原文中常与政治判断绑定，迁移时应只取"定期复核"这一操作含义。

### 容易混淆的邻近方法论

- 与"关键路径法"不同：关键路径找的是时间上的最长链，本 skill 找的是逻辑上的规定关系。
- 与"OKR 聚焦"不同：OKR 是目标层收敛，本 skill 是矛盾层定位，前者不回答"为什么是这三件事"。
