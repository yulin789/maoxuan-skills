# 调查研究：在信息不全时拿到可用判断

## R — 原文 (Reading)

> 「你对于那个问题不能解决么？那末，你就去调查那个问题的现状和它的历史吧！你完完全全调查明白了，你对那个问题就有解决的办法了。」
>
> 「三十个生产队他调查三个就行了，一个最坏的，一个中等的，一个最好的。」
>
> — 毛泽东，《反对本本主义》（1930，第1卷 p81-82）；《大兴调查研究之风》（1961，第6卷 p1370）

---

## I — 方法论骨架 (Interpretation)

调查不是"多了解情况"，而是为了让一个具体决定有事实底稿。所以它从决定出发，不从好奇心出发。

第一步是把调查目的钉死：不是"了解这个行业"，而是"这份决定会碰到谁的利益、谁在抵触"。目的不清，纲目就会散，收集回来的必然是一堆无法估量的材料——作者叫它"挂了一篇狗肉账"。

第二步是先把纲目写好（大纲下再列细目），不靠临场想问题。第三步是选人：能说清实情的人、不同位置的人都要在座，无关者不必在场，至少三人，否则会"囿于见闻"。第四步是开讨论式的会，提中心问题、允许互驳——一个人单讲经验容易错。

第五步是本人到场，不能只看书面汇报，"因为二者是两回事"。第六步是先彻底弄清一处，再推及其他。第七步是自己记录，不假手于人。

当条件不允许跑遍所有点时，用两点补充：一是三点抽样（最好/中等/最差各一个），先看分布形状再谈比例；二是自己搞一两个点，其余派班子去搞、自己定任务和口径——"我是间接的，并没有直接调查"，但方向与问题由自己定。

整套方法的产出不是"情况汇总"，而是一张力量表＋一句"目前有无把握下决心"。

## A1 — 应用示例 (Application Example)

### 示例 1: 五县三十二天，推翻"糟得很"的现成结论
- **类型与来源**: 原书亲历案例（c01；《湖南农民运动考察报告》1927，第1卷 p31-34）
- **问题/输入**: 当时党内与外界对农民运动的通行判断是"糟得很"；作者手上只有二手议论。
- **方法论的使用**: 亲自到湘潭、湘乡、衡山、醴陵、长沙五县，实地看农会做了什么、谁在反对、反对者的身份与理由；用"革命/反革命"的实际行为而不是传闻来给人分档。
- **结论**: 农民运动"好得很"，"糟得很"是站在对立面的人的说法。
- **结果**: 原书交代了结论与调研范围；具体的调查表与样本量未说明。

### 示例 2: 一九六一年的三点抽样
- **类型与来源**: 原书亲历案例（c04；《大兴调查研究之风》1961，第6卷 p1370-1372）
- **问题/输入**: 中央对农村实情不明，"官做大了"，下面报上来的数字互相矛盾。
- **方法论的使用**: 不追求全面普查，先选三个生产队——最好、中等、最差——亲自看、亲口问、亲手记；看群众"是不是面有菜色"。
- **结论**: 情况比报表严重；据此重设政策。
- **结果**: 原书提到由此推动 1961 年的调查与调整；三个点的选择理由与最终政策效果未逐项说明。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 要做一个人事、采购、定价、迁移、合作类的决定，但手上的依据全是汇报、会议纪要或"大家都这么说"。
2. 团队里对同一件事有两种相反说法，谁也说服不了谁，因为双方都没有共同的原始材料。
3. 已经下了决定，但落地时遭遇莫名其妙的抵触，怀疑自己一开始就判断错了对象。
4. 需要向老板/投资人解释"为什么选这个方案"，而对方问"你怎么知道的"。
5. 事情反复失败，每次都换做法，但从未回头确认过前提事实。

### 语言信号 (用户的话里出现这些就应激活)

- "这个决定我只能拍脑袋了" / "I don't have the data"
- "下面都说……" / "everyone says…"
- "先做了再说" / "let's just ship it"
- "到底该听谁的" / "whose numbers do I trust"
- "这个方案有什么依据" / "how do you know"

### 与相邻 skill 的区分

- 与 `maoxuan-priority` 的区别：调查解决"事实是什么"，优先级解决"事实都清楚了，先做哪件"。调查未完成时不该进入优先级判断。
- 与 `maoxuan-epistemology` 的区别：本 skill 负责取回材料，epistemology 负责判断已有结论是否已被实践检验。
- 与普通"用户访谈/市场调研"的区别：本 skill 强制"目的→纲目→选人→讨论→亲自→记录"的顺序，且把"能否下决心"作为出口判据，而不是产出一份报告就结束。

## E — 可执行步骤 (Execution)

**必需输入**：① 待决问题一句话；② 可召集的知情人名单（含其位置/角色）；③ 时间与接触成本上限。
**缺失时询问**：若"待决问题"说不清，先要求把它改写成"在 A 与 B 之间选"或"是否要做 C"的可判定形式；若知情人只有管理者，明确告知结论会有偏差。

**交付物与完成标准**：一张力量表（谁受影响／谁有决定权／谁在抵触／谁可争取）＋每个判断对应的事实条目（含来源人与日期）＋一句"情况明/不明，有无把握下决心"。

1. **钉死调查目的**
   - 完成标准：能用一句话回答"这份决定会改变谁的行为"，并写出 3 条必须回答的子问题。
2. **写调查纲目**
   - 完成标准：3–5 个大项，每项下至少 3 个细目；细目是"可记录的事实"而不是"看法"。
3. **选人到会**
   - 完成标准：名单里至少 3 人，且包含 1 名一线执行者、1 名受影响方、1 名持相反意见者；无关者移出。
   - 判停条件：若某类知情人无法接触，记录为缺口并在输出中标注，不假装覆盖。
4. **开讨论式调查会**
   - 完成标准：会上至少有一次观点对立被摆到桌面并被追问依据；记录的是原话而不是你的归纳。
5. **亲自到场一处**
   - 完成标准：你本人观察/参与了一个真实场景（不是听汇报），并记下至少 1 条与先前判断不符的观察。
6. **三点抽样（无法普查时）**
   - 完成标准：最坏/中等/最好各取一例，写出三者差异的方向，而非仅给平均值。
7. **自己做记录并汇总**
   - 完成标准：力量表每格都有来源；"情况明/不明"的结论有明确依据（缺哪一类信息）。
8. **出口判断**
   - 完成标准：给出"可以下决心 / 需补查 X / 不能决定"三者之一；若为后两者，列出补查清单。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 问题已有可靠的一手数据且结论无争议（如合规判定、已完成的 A/B 实验结果）——再调查只是拖延。
- 需要的是"快速试错"而不是"先看清再动"：可逆的小实验应直接做，用结果代替调查。
- 时间窗短于最小调查成本（如当天必须决定）：改用三点抽样或单点验证，并在输出中标注置信度低。

### 作者在书中警告的失败模式

- **狗肉账式调查**（x03）：只挂材料、不作估量，"像挂了一篇狗肉账"。表现为记录很多但不指向任何判断。
- **不作调查就发号施令**（x01）：看到一点表面就宣布政见。
- **盲目执行上级指示**（x02）：以为"上级说的"就是依据，反而是一种怠工。
- **调查研究工作不做了**（x23，作者 1961 年自陈）："这些年来，我们的同志调查研究工作不做了。要是不做调查研究工作，只凭想像和估计办事，我们的工作就没有基础。"
- **不做正确的调查同样没有发言权**（p85 注）：方法错，结论照样废。

### 作者的盲点 / 时代局限

- 原文的调查目的绑定"阶级估量"，迁移到现代组织时要换成"利益相关方与决策影响"，否则会硬套阶级框架。
- 书中隐含假设"调查者能进场、被调查者会说真话"；在权力不对等的组织里，一线会因恐惧而系统性说谎。本 skill 保留 f42 的对策（找边缘知情人、平等态度、多渠道），但仍不足以完全消除。
- 未讨论样本量与统计推断；三点抽样只能给分布形状，不能给比例。需要定量结论时应另配抽样方法。
- 合集内没有《寻乌调查》《长冈乡调查》全文，调查表的具体设计无法从本书完整复原（见 `.cangjie/needs-review.md`）。

### 容易混淆的邻近方法论

- 与"精益创业的最小可行实验"不同：本 skill 先求看清，后者先求试错；两者可组合（先三点抽样定位，再小实验验证）。
- 与"设计思维的用户访谈"不同：本 skill 要求事先定纲目并允许会上互驳，不鼓励开放式共情访谈。
