# 毛泽东选集（第一至七卷合集：原版五卷＋静火版六、七卷＋润之赤旗版六、七卷＋草堂版第六卷） — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 不作政治评价、历史定性与人物评价，只提取可复用的方法结构
- 不处理卷六、卷七中已被 1981 年决议否定的具体结论（如继续革命理论）
- 不替代法律、财务、安全等专业判断

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 没有调查就没有发言权：判断之前先到现场，用三点抽样控制成本
2. 一段时间内只能有一个中心工作：主要矛盾由"规定性"判定，不由"最紧急"判定
3. 集中优势力量打歼灭战：在单点形成压倒性优势，打完一个再打下一个
4. 一般号召必须配个别指导：先在一两个单位突破一点取得具体经验
5. 从群众中来到群众中去：把分散意见集中化，再回到实践检验、再集中
6. 卷六、卷七只取方法不取结论：结论多已被历史否定，可迁移的是推理结构
