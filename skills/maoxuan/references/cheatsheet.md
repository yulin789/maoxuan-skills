# 决策规则速查 — 毛泽东选集（第一至七卷合集：原版五卷＋静火版六、七卷＋润之赤旗版六、七卷＋草堂版第六卷）

| 能力 | 一句话规则 |
|---|---|
| 调查研究：在判断之前先到现场 | 用开调查会、三点抽样与亲自记录，把"听说的"换成"看到的"，再谈判断。 |
| 主要矛盾与唯一中心工作 | 用"规定性"而不是"最紧急"找出主要矛盾，并把它收敛为一段时间内唯一的中心工作。 |
| 一般号召与个别指导：把决定推到一线 | 先在一两个单位突破一点取得具体经验，再用个别指导带起一般号召。 |
| 班子议事与团队运行规程 | 十二条习性把"开会"变成可执行的议事、分工与检查规则。 |
| 集中优势力量做局部突破 | 承认总体劣势，在单点造出三倍以上局部优势，按"全歼"标准打完再打下一个。 |
| 组织病灶诊断与纠错 | 先看症状分布判断病灶在制度还是个人，再按可指认的行为清单配纠治动作。 |
| 认识的两个飞跃与实践检验 | 认识的成立要过两道闸——能否上升为机制、能否在实践中得到预期结果。 |
| 矛盾特殊性：逐层缩小到"这一处" | 五层缩小定位"这一处"的特殊点，并用三病自检防止主观、片面、表面。 |
| 战略藐视与战术重视：两层同时成立 | 战略层给结构性理由、战术层拆成可完成的"敲牙齿"序列，两层缺一即错。 |
| 三分力量图与争取中间势力 | 按利益划三档阵营，用"自己够强、尊重利益、能一步步赢"三条件判断能否争取中间。 |
| 党八股六条自检：为什么没人看、没人执行 | 用六条可指认的病征判断材料为何无人读，并按"先定读者与动作"的顺序改。 |
| 定期综合报告制度：把请示报告参数化 | 两月一次、千字上限、必写"问题与倾向"，并规定上级必须回应。 |
| 十大关系法：每个目标都要问"真想还是假想" | 把目标配成关系对，定主次与比例，并用资源配置反查"真想还是假想"。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
