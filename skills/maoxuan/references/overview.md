# 《毛泽东选集》七卷合集 · 整书概览

## 这本书是什么

一部**决策与组织工作的方法记录**，不是一部理论教科书，也不是一部历史叙述。

底本是民间编纂的七卷合集，由五种版本拼合：

| 部分 | 版本 | PDF 页码 | 说明 |
|---|---|---|---|
| 第一至四卷 | 1991 年第二版 | 18–884 | 1925–1949，方法论密度最高 |
| 第五卷 | 1977 年版 | 885–1185 | 1949–1957，含《论十大关系》《关于正确处理人民内部矛盾的问题》 |
| 第六、七卷 | 静火版（2009） | 1186–1794 | 选文讲究、校对较细，1957–1976 |
| 第六、七卷 | 润之赤旗版（3.0） | 1808–2813 | 收录极多但顺序较乱，可与静火版互校 |
| 第六卷 | 草堂闲人版 | 2814–3246 | 仅第六卷，另一种编次 |

同一篇文章在不同版本里的文字有差异，页码以本 PDF 为准。索引见 `books/maoxuan/.cangjie/index/articles.tsv`（244 篇）。

## 一句话主旨

在**信息不全、力量不足、目标长远**这三重约束下，作者反复使用的是一条闭环：

> 先到现场取得第一手材料 → 在许多矛盾中找出当前唯一的主要矛盾 → 把有限力量集中到一点打出局部优势 → 用"一般号召＋个别指导"推到一线 → 靠检查与报告回到现场修正判断 → 再调查。

这条闭环的每一环都有对应的失败模式，也都有作者本人付出代价换来的反例（见各能力卡的 B 段）。

## 五个判断，与这本书的主要分歧点

1. **主要矛盾的判据是"规定性"，不是"最紧急"。** 作者在《矛盾论》里给的是结构判据：它的存在规定其他矛盾以什么形态出现。营销与项目管理语境里流行的"紧急重要四象限"是时间判据，两者会给出不同答案。
2. **一个时期内只能有一个中心工作。** 作者的原话是"不能同时有许多中心工作"。多数现代管理建议（多线并行、组合投资）与这条直接冲突；本书的立场是：并行的前提是已经有人在替你把其他线守住。
3. **调查是判断的前置条件，不是判断之后的补充。** "没有调查，没有发言权"是禁令式表述。现代做法常把调研放在方案成型之后做验证，作者会认为那已经不叫调查。
4. **集中是空间上的优势，不是总量上的投入。** 三倍、四倍、五六倍是相对对手的倍数，而不是预算的绝对值。
5. **方法可迁移，结论不可迁移。** 卷六、卷七的大量具体结论已被 1981 年《关于建国以来党的若干历史问题的决议》否定。本书只取其中的推理结构（如"先检查自己的政策再批评下面"的归因顺序），不取政治结论。

## 这本书的盲点（读的时候要带着）

- **胜利者视角**：所有案例都是经过挑选的成功与失败，没有"照这套方法做但仍然失败"的样本。
- **对信息成本的估计偏乐观**：作者面对的是一支有纪律、有共同目标的队伍；在没有强制力的组织里，"亲自出马""开调查会"的成本高得多。
- **方法的道德风险**：同一套"区分敌我"的技术，既可用于争取中间势力，也可用于清洗。能力卡在使用这类条目时都加了边界。
- **缺少年份跨度上的自我修正**：同一作者在不同时期对同一问题的说法有变化（如对"群众运动"的态度）；本书按主题取用，不追时间线。
- **文本残缺**：本 PDF 抽取存在系统性吞字（政→治、政府→府、政策→策、起来→起）。引文已按上下文复原，无法复原处标〔原文缺字〕。

## 怎么用这套能力

1. 面对真实问题，先读入口 `SKILL.md` 的路由表，按意图加载**一张**能力卡。
2. 能力卡的 E 段是可执行步骤，R 段是原文依据，B 段是"什么时候不该用"。
3. 需要术语精确含义时查 `glossary.md`。
4. 只想要结论、不需要原文依据时查 `cheatsheet.md`。

## 不适合用它做什么

- 政治评价、历史定性、人物评价。
- 需要专业资质判断的领域（法律、财务、安全）。
- 纯技术故障排查。
- 角色扮演或模仿文风。
