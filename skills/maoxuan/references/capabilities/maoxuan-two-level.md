# 战略藐视与战术重视：两层同时成立

## R — 原文 (Reading)

> 「我们的战略是"以一当十"，我们的战术是"以十当一"，这是我们制胜敌人的根本法则之一。」
>
> 「一切反动派都是纸老虎。看起来，反动派的样子是可怕的，但是实际上并没有什么了不起的力量。」
>
> — 毛泽东，《中国革命战争的战略问题》（1936，第1卷 p147）；《和美国记者安娜·路易斯·斯特朗的谈话》（1946，第4卷 p693）；《美帝国主义是纸老虎》（1956，第5卷 p1065）

---

## I — 方法论骨架 (Interpretation)

这不是"既要自信又要谨慎"这类正确的废话，而是一个**分层规则**：两层必须同时成立，只取一层必错。

**战略层**看全体、长远、本质：以一当十，完全轻视。判断依据不是士气，而是结构性理由——决定胜负的是人心向背而非一两件新式武器；对手的强是"暂时的、局部的"，它脱离多数人支持这一点是长期的。

**战术层**看局部、当下、具体：以十当一，务必重视。对手"有爪有牙"，每一次具体交锋都可能输，必须集中兵力、认真准备、不打无把握之仗。

两层之间的转换不是心理调节，而是**拆解**：它有十个牙齿，第一次敲掉一个，还有九个，再敲掉一个……牙齿敲完了还有爪子，"一步一步地认真做，最后总能成功"。战略上的藐视，靠战术上的逐项兑现才站得住；没有拆解的藐视是空话。

作者还给了转化的双向机制：真老虎与纸老虎可以互变——取得统治权力之前和之后、面临人民决死斗争时，强的一方会变成纸老虎；反之脱离多数人者虽强必弱。

两种失败模式各自对应一边：只在战略层轻视 → 轻敌冒进（"六路分兵""全线抵御""军事平均主义"，结果为敌所制）；只在战术层重视 → 畏敌、不敢胜利。

## A1 — 应用示例 (Application Example)

### 示例 1: 一九四六年的"纸老虎"判断
- **类型与来源**: 原书案例（c06；《和美国记者安娜·路易斯·斯特朗的谈话》1946，第4卷 p693）
- **问题/输入**: 全面内战爆发，对手拥有美国支持的装备与兵力优势，内部普遍畏战。
- **方法论的使用**: 在战略层给出结构性判断——"决定战争胜败的是人民，而不是一两件新式武器"；同时战术层不轻敌，按十大军事原则逐次集中兵力打歼灭战。
- **结论**: 战略判断给方向，战术纪律给兑现方式。
- **结果**: 原书给出判断与原则；战局发展与判断的关系由后续历史验证，当时并未给出时间表。

### 示例 2: 第五次反"围剿"——只有战术重视，没有战略藐视
- **类型与来源**: 原书反面案例（c09；《中国革命战争的战略问题》1936，第1卷 p147 前后）
- **问题/输入**: 面对优势对手，采取"御敌于国门之外""六路分兵""全线抵御"。
- **方法论的使用**: 反证——处处设防等于处处薄弱，每一处都以少对多，既没在战术上集中，也没在战略上判断"长期看对手必弱"。
- **结论**: 不是勇气问题，是两层规则同时失效。
- **结果**: 原书归之为"军事平均主义"，结局为被迫转移。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 面对远强于自己的对手（大厂、巨头、强势渠道），团队士气涣散或盲目乐观。
2. 战略上喊"我们必胜"，但每次具体战役都打得很糙。
3. 反过来：每个细节都很谨慎，但不敢下"长期看我们会赢"的判断，导致资源不敢投。
4. 需要在融资/内部动员中同时表达"有信心"和"不轻敌"。
5. 长期战事中判断"该进攻还是该熬"。

### 语言信号 (用户的话里出现这些就应激活)

- "对手太强了，没戏" / "they're too big"
- "战略上藐视，战术上重视" / "paper tiger"
- "必胜" / "we'll definitely win"
- "长期主义" / "play the long game"
- "先打赢这一仗再说" / "one battle at a time"

### 与相邻 skill 的区分

- 与 `maoxuan-concentrate` 的区别：concentrate 给"这一仗投多少、怎么算打完"的配置规则；本 skill 给的是"凭什么在整体劣势下还敢打"的判断框架，两者是配套关系。
- 与 `maoxuan-epistemology` 的区别：epistemology 检验单个判断真假，本 skill 处理"同一对象在不同层级上结论相反"的情形。
- 与"积极心态/成长型思维"的区别：本 skill 的轻视必须建立在结构性理由（人心、长期、资源可持续）上，不是情绪调节。

## E — 可执行步骤 (Execution)

**必需输入**：① 对手/困难的量化描述（规模、资源、优势项）；② 己方可长期依赖的结构性因素；③ 未来 3–6 个月的具体交锋清单。
**缺失时询问**：若说不出"长期看我们凭什么"，先不要用本 skill——那是愿望，不是判断。

**交付物与完成标准**：一份双层判断书——战略结论及依据／战术清单／拆解路径／两种失败模式的自检。

1. **分层陈述对象**
   - 完成标准：明确本次讨论的是"全局长期"还是"某一具体交锋"，两者分表写。
2. **战略层：给结构性依据**
   - 完成标准：列出至少 2 条不依赖短期资源的理由（人心向背、成本结构、时间站在谁一边），并说明可被什么事实推翻。
3. **承认对手的"爪牙"**
   - 完成标准：写出对手 3 项真实优势，不美化、不贬低。
4. **战术层：拆成可完成序列**
   - 完成标准：把"打败它"拆成 3–8 个可独立完成的小目标，每个有明确完成标志。
5. **定第一击**
   - 完成标准：选出第一个"牙齿"，说明为何先敲它（最弱、最关键、最可积累）。
6. **设资源与节奏**
   - 完成标准：每次交锋的投入不超过可持续水平；两个交锋之间留恢复期。
7. **双失败模式自检**
   - 完成标准：分别回答"我们是否在轻敌冒进"与"我们是否在畏敌不战"，各给一条证据。
8. **定期重判**
   - 完成标准：每个阶段结束时重做第 2 步；若结构性依据消失，战略结论必须改，不许用"坚持就是胜利"覆盖。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 对手是自然灾害、市场周期等无人格对象："人心向背"类依据不适用，应改用风险工程。
- 己方没有任何可持续的结构性优势，且资源即将耗尽：此时需要的是止损或转向，不是战略藐视。
- 谈判桌上的即时决策：分层判断需在准备阶段完成。

### 作者在书中警告的失败模式

- **只在战略层轻视**（x20）：轻敌冒进，"六路分兵""全线抵御"。
- **只在战术层重视**：处处谨慎，不敢胜利，错失转折点。
- **纸老虎判断被滥用**：把任何强敌都说成纸老虎而不做战术拆解，等于取消第 4–5 步。

### 作者的盲点 / 时代局限

- 原文的"人民"是明确的政治主体，现代组织里"人心向背"需要换成可观测指标（留存、口碑、员工留任），否则无法验证。
- "纸老虎"论断带有强烈的政治动员功能，用于内部宣传时会掩盖真实风险；建议只在内部分析中使用，对外表述需谨慎。
- 原文假定时间站在己方一边；当时间站在对手一边时（如对手在快速迭代），整条推理链需要反转。

### 容易混淆的邻近方法论

- 与"斯多葛式区分可控与不可控"不同：本 skill 不处理情绪，处理的是层级间的结论冲突。
- 与"蓝海/错位竞争"不同：那些是换战场，本 skill 是在同一战场上调整层级判断。
