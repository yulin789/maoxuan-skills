# 党八股六条自检：为什么没人看、没人执行

## R — 原文 (Reading)

> 「党八股的第一条罪状是：空话连篇，言之无物。我们有些同志欢喜写长文章，但是没有什么内容，真是"懒婆娘的裹脚，又长又臭"。」
>
> 「党八股的第五条罪状是：甲乙丙丁，开中药铺。」
>
> — 毛泽东，《反对党八股》（1942，第3卷 p492、p494）

---

## I — 方法论骨架 (Interpretation)

《反对党八股》不是一篇修辞学文章，是一份**诊断清单**：把"文风不好"这种无法执行的整体评价，拆成八条可以对号入座、可以逐条改的症状。

前六条针对的是当事人能改的毛病：①空话连篇、言之无物——"长而空"没人看，"短而空"也不行，要的是有内容；②装腔作势、借以吓人——靠架势代替论证，"辱骂和恐吓决不是战斗"；③无的放矢、不看对象——不先问给谁看；④语言无味，像个瘪三；⑤甲乙丙丁开中药铺——只按外部标志分类，不按内部联系，罗列一大串却不提出问题、不分析问题、不解决问题；⑥不负责任，到处害人。

后两条是后果：⑦流毒全党、妨害革命；⑧传播出去、祸国殃民。

作者给的修法顺序很实用：**先说清"给谁看、要解决什么"，再决定长短与形式**——"到什么山上唱什么歌""看菜吃饭，量体裁衣"。四条对症规则也都可以直接执行：写不出的时候不硬写；写完至少看两遍，"竭力将可有可无的字、句、段删去"；不生造除自己之外谁也不懂的形容词；写东西时始终想到"使每个普通工人都懂得"。

第五条的分类标准最容易被忽略却最重要：**按事物的内部联系分类，不按外部标志分类**——"问题就是事物的矛盾"。

## A1 — 应用示例 (Application Example)

### 示例 1: 一份"没人看"的长报告
- **类型与来源**: 原书案例（《反对党八股》1942，第3卷 p492 起，第一条罪状的现场批评）
- **问题/输入**: 当时党内文件动辄长而空，"只有一种解释，就是下决心不要群众看"。
- **方法论的使用**: 用第一条罪状对号——先问"给谁看"，再问"有没有内容"；给出的解法不是"写短点"，而是"有内容、有对象、按内部联系组织"。
- **结论**: 长度不是问题，空才是问题；"短而空"同样不合格。
- **结果**: 原文以苏联战争时期的短文件作对照，未给出改造后的量化指标。

### 示例 2: 《晋绥日报》的弓弦拉得太紧又泄气
- **类型与来源**: 原书案例（c18；《对晋绥日报编辑人员的谈话》1948，第4卷 p767-768）
- **问题/输入**: 反右倾时报纸尖锐泼辣、批注很多；纠"左"之后又"不够明确，不够泼辣，材料也少了，使人不大想看"。
- **方法论的使用**: 作者用"文武之道，一张一弛"判断节奏——批注式批判越用力，越要同步留出"弛"的时段，否则纠偏本身变成新的偏差。
- **结论**: 文风的松紧是政策节奏的外在读数。
- **结果**: 要求报社"作一次全面的总结"；后续改版效果原文未展开。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 一份方案发下去，没人读、没人执行，作者归因于"执行力"。
2. 周报/月报越写越长，全是"加强了、提升了、深化了"。
3. 汇报材料堆满分类（甲乙丙丁、一二三四），但看不出结论。
4. 对外文档用满行业黑话，用户看完不知道要做什么。
5. 需要把技术内容讲给非技术决策者听。

### 语言信号 (用户的话里出现这些就应激活)

- "大家都不看文档" / "nobody reads the doc"
- "写得不够清楚" / "unclear writing"
- "太长了" / "too long"
- "全是套话" / "all buzzwords"
- "讲给老板听不懂" / "explain it to a non-technical exec"

### 与相邻 skill 的区分

- 与 `maoxuan-reporting` 的区别：reporting 规定"多久报一次、报什么内容"，本 skill 规定"这份东西怎么写才有人看"；两者常一起用。
- 与 `maoxuan-deploy` 的区别：deploy 解决"决定怎么推下去"，本 skill 解决"推下去的那份材料本身有没有问题"。
- 与通用"写作技巧"的区别：本 skill 不教修辞，只给六条可核对的病征与四条修法。

## E — 可执行步骤 (Execution)

**必需输入**：① 待改的文稿（或讲话提纲）；② 目标读者是谁、他们要用它做什么决定。
**缺失时询问**：若说不出读者要做什么决定，先不要改文字——那是"无的放矢"（第三条罪状）。

**交付物与完成标准**：改后文稿＋一份六条自检表（每条标注"有/无/已改"）＋一句话的"读者要做的动作"。

1. **写清读者与动作**
   - 完成标准：一句话——"看完这份东西，读者应当做 X"。
2. **查第一条：有没有内容**
   - 完成标准：删掉所有不含信息的句子后，剩下的部分仍能支撑结论。
3. **查第二条：有没有靠架势**
   - 完成标准：找出所有形容词与断言，逐个补证据或删除。
4. **查第三条：有没有对象错位**
   - 完成标准：标出所有读者不认识的术语，逐个替换或加一句解释。
5. **查第五条：分类是否按内部联系**
   - 完成标准：检查每个小标题，能回答"这一节解决哪个问题"；不能的合并或删除。
6. **删可有可无的字句段**
   - 完成标准：通读两遍，第二遍只做删除；篇幅至少压缩 20%（除非内容本身要求长）。
7. **做"普通工人能懂"测试**
   - 完成标准：找一位非本领域的同事读，能复述出"要做什么"。
8. **定节奏**
   - 完成标准：若这是周期性材料，判断当前该"张"还是该"弛"，避免连续高压批注后突然泄气。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 法律文书、合规披露、安全规程：表述的精确性优先于可读性，不能为"通俗"牺牲限定条件。
- 需要留痕的正式决议：不能为求短而省略责任与时限。
- 与专业同行的深度技术文档：术语是效率工具，不必降维。

### 作者在书中警告的失败模式

- **长而空**（x05）：下决心不要群众看。
- **装腔作势吓人**（x06）：用架势代替论证。
- **无的放矢**（x07）：不看对象。
- **开中药铺**（x08）：只罗列不分析。
- **不负责任**：写出去会影响很多人，所以非改不可。

### 作者的盲点 / 时代局限

- 文章写于 1942 年整风语境，批评带有强烈的政治动员性质；其中的"党八股"后来也被用作政治标签，需只取"六条病征"的诊断功能。
- "使每个普通工人都懂得"在专业分工极细的今天不能绝对化，否则会损失必要的精确性。
- 原文未讨论"读者不读"也可能是渠道问题（发在哪里、什么时候发），而不只是文风问题。

### 容易混淆的邻近方法论

- 与"金字塔原理"不同：金字塔原理给结构模板，本 skill 给病征清单。
- 与"plain language"运动不同：本 skill 不追求简化词汇，追求"有对象、有内容、有分析"。
