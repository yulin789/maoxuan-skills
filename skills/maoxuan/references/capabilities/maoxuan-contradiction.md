# 矛盾特殊性：逐层缩小到"这一处"

## R — 原文 (Reading)

> 「不同质的矛盾，只有用不同质的方法才能解决。」
>
> 「研究问题，忌带主观性、片面性和表面性。」
>
> — 毛泽东，《矛盾论》（1937，第1卷 p191-195、p192），《矛盾论》（1937，第1卷 p196）

---

## I — 方法论骨架 (Interpretation)

《矛盾论》最常见的误读是把它当成"凡事都有两面"的鸡汤。它的真正内容是**特殊性**：矛盾普遍存在，但每一处矛盾都有质的不同，因此方法必须随质而变。

作者给了五层缩小法：①这是哪一种物质运动形式的矛盾（机械的、物理的、化学的、社会的、思维的）；②这种运动形式在该发展过程中有何特殊矛盾；③该过程矛盾的各方面各有什么特点；④该过程在其各发展阶段上的矛盾有何特点；⑤各阶段矛盾的各方面又各有什么特点。每一层都必须做具体分析，"都不能带主观随意性"。

所以他举的例子是方法而非态度：劳资矛盾用社会主义革命解决，党内矛盾用批评与自我批评解决——不是因为后者更温和，而是因为矛盾的质不同。

配套的是三病自检：**主观性**（不从材料从愿望出发）、**片面性**（只了解一方不了解另一方，作者列了十几组"只了解…不了解…"）、**表面性**（粗枝大叶，望一望就动手）。三病不是道德批评，是可核对的推理缺陷。

还有一条防滥用：**有同一性不等于必然转化**。矛盾的同一性要"在一定的必要的条件之下"；缺乏必要条件，就没有任何同一性——战争与石头之间不存在转化路径。这砍掉了一厢情愿式推演。

## A1 — 应用示例 (Application Example)

### 示例 1: 同一个"吵架"，方法为什么不同
- **类型与来源**: 原书论述（《矛盾论》1937，第1卷 p191-195）
- **问题/输入**: 两处都表现为"冲突"，一处是劳资之间的利益对抗，一处是党内的意见分歧。
- **方法论的使用**: 按五层缩小判断质：前者是不同阶级在经济利益上的矛盾，后者是同一组织内部在认识与作风上的矛盾；质不同，方法不同——前者走向社会革命，后者用批评与自我批评、团结—批评—团结。
- **结论**: 先判质，再选方法；用错方法（把党内分歧当敌我矛盾，或把利益对抗当认识问题）都会失败。
- **结果**: 原书给出了判断依据；具体历史事件的执行细节未展开。

### 示例 2: 三打祝家庄——前两次败在"情况不明"
- **类型与来源**: 原书案例（《矛盾论》1937，第1卷 p195 前后的引证）
- **问题/输入**: 头两次打祝家庄，因不了解盘陀路、未拆散三庄联盟而失败。
- **方法论的使用**: 第三次改变方法——从调查情形入手，摸清盘陀路、拆散联盟、布置伏兵；作者以此说明"情况不明，方法不对"就打败仗，方法来自对特殊性的把握。
- **结论**: 失败往往不是决心不够，是没有做特殊性分析。
- **结果**: 原书以小说情节作辩证法的例证；细节为文学叙述。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿一个成功案例/行业最佳实践直接套到自己的场景。
2. 两个部门起冲突，一律按"沟通问题"处理，处理完照旧。
3. 把不同阶段的业务当成同一阶段（用成熟期打法做冷启动）。
4. 判断"这个也会好转"，但说不清需要什么条件。
5. 分析报告只列现象，不区分这一次的特殊点。

### 语言信号 (用户的话里出现这些就应激活)

- "别人都是这么做的" / "best practice says"
- "照搬就行" / "just copy the playbook"
- "他们就是沟通不畅" / "it's a communication issue"
- "早晚会好" / "it'll turn around"
- "这个和那个是一样的" / "same thing as last time"

### 与相邻 skill 的区分

- 与 `maoxuan-priority` 的区别：priority 找"哪一个是主要矛盾"，本 skill 判断"这个矛盾是什么质、属于哪一层"；先判质，再定主次。
- 与 `maoxuan-stakeholder` 的区别：stakeholder 按利益划三档阵营，本 skill 分析矛盾本身的结构与阶段。
- 与"类型学/分类框架"的区别：本 skill 不给固定分类，而给"逐层缩小"的追问顺序。

## E — 可执行步骤 (Execution)

**必需输入**：① 一个具体矛盾（谁与谁、在什么事上、什么时候开始）；② 已有的现象材料；③ 拟采用的方法及其来源。
**缺失时询问**：若只得到"团队氛围不好"这类整体描述，先要求拆成至少两个具体对立面。

**交付物与完成标准**：一份特殊性分析——五层定位／三病自检／方法选择理由／转化条件清单。

1. **写清对立面**
   - 完成标准：至少两方，各有明确诉求，不能用"大家"作为一方。
2. **第一层：属于哪种矛盾**
   - 完成标准：给出类别并说明判断依据（利益、认识、结构、资源……）。
3. **第二、三层：过程与方面特点**
   - 完成标准：写出该过程的基本矛盾，以及各方面"强在哪、弱在哪"。
4. **第四、五层：阶段判断**
   - 完成标准：明确当前处于哪个阶段，并给出阶段划分依据（哪些矛盾激化、哪些已解决、哪些新发生）。
5. **三病自检**
   - 完成标准：逐条回答——我是否从愿望出发？我是否只了解一方？我是否只看表面？每条给出补证动作。
6. **选方法并说明为何不同质**
   - 完成标准：所选方法能与"质"对应；若与既有做法相同，说明为何本处不需要变。
7. **列转化条件**
   - 完成标准：若要判断"会变好/能合作"，列出必要条件并逐条判定是否具备；不具备的写"需创造条件"而不是"必然"。
8. **设复核点**
   - 完成标准：给出下一次重新判断阶段的时间点与触发条件。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 需要快速统一行动的紧急处置：五层分析会拖慢决策，应先按预案执行，事后补分析。
- 纯技术故障排查：因果链清楚时，用故障树更高效。
- 对抗性谈判的临场：分析放在准备阶段，不当场做。

### 作者在书中警告的失败模式

- **主观性**（x02）：从愿望出发，把"应该怎样"当"实际怎样"。
- **片面性**：只了解一方，只了解顺利不了解困难。
- **表面性**：望一望就动手，把现象当本质。
- **无条件转化论**：把"可能"当"必然"（f10）。

### 作者的盲点 / 时代局限

- 《矛盾论》的例证高度依赖阶级斗争语境，直接迁移到组织管理时，"矛盾的质"需要重新定义，否则容易把正常的意见分歧上升为路线斗争。
- 五层缩小在实践中容易过度细分，导致分析精致但无法行动；应配合"够用即止"的判停。
- 原文未处理"多矛盾同时存在且相互纠缠"的情形，只做了主次之分。

### 容易混淆的邻近方法论

- 与"SWOT/波特五力"不同：那些是固定维度清单，本 skill 是追问顺序。
- 与"辩证思维（正反合）"不同：本 skill 要求落到层与阶段，不接受"两方面都重要"式结论。
