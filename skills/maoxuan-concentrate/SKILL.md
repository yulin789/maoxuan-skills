# 集中优势力量做局部突破

## R — 原文 (Reading)

> 「从敌军诸阵地中，选择较弱的一点（不是两点），猛烈地攻击之。」
>
> 「集中优势兵力，各个歼灭敌人……伤其十指不如断其一指。」
>
> — 毛泽东，《集中优势兵力，各个歼灭敌人》（1946，第4卷 p695-696）；《目前形势和我们的任务》（1947，第4卷 p724-725）

---

## I — 方法论骨架 (Interpretation)

整体资源少于对手时，正面拼消耗必输。可行的是反过来：承认总体劣势，但在每一个具体点上制造局部绝对优势，打完一个再打下一个。

三个参数必须同时确定，缺一个就退化成蛮干或分散：

**选点**——选较弱的一路，或较少援助的、地形民情对它不利的一路。作者强调"不是两点"：两点同时开，每一点都够不上绝对优势。**倍数**——三倍、四倍、五六倍，即不是"稍多一点"，而是压倒性。**目标**——全歼而不是击溃。理由是击溃战只把对手赶走，全歼则能补充自己、沮丧对手，并且能速决；"战术和战役上的速决，是战略上持久的必要条件"。

还有两条容易忽略的排序：以歼灭对方有生力量为主要目标，不以保守或夺取地方为主要目标（为歼敌可暂时放弃地方，但凡能守能夺且有意义的必须守夺）；以缴获补充自己——"人力物力的来源，主要在前线"，也就是边打边补，打完一仗要能变强一点。

反面的样子叫"平分兵力，处处攻击"，结果是处处不足、一路也歼不了。

## A1 — 应用示例 (Application Example)

### 示例 1: 苏中与定陶——一口一口吃掉
- **类型与来源**: 原书案例（c08；第4卷 p695-696 及战例叙述）
- **问题/输入**: 兵力总体少于对手，且对方分多路推进。
- **方法论的使用**: 不分散迎敌，而是每战集中三到六倍于敌一部的兵力，选其较弱一路包围全歼；打完迅速转移，再打下一路。
- **结论**: 局部绝对优势可以逐次改变总体对比。
- **结果**: 原书给出战果与兵力倍数；具体每次战斗的决策细节只部分叙述。

### 示例 2: 第五次反"围剿"——平分兵力的代价
- **类型与来源**: 原书反面案例（c09；第1卷《中国革命战争的战略问题》p147 前后）
- **问题/输入**: 面对装备与兵力占优的对手，采取"御敌于国门之外""六路分兵""全线抵御"。
- **方法论的使用**: 反证——处处设防等于处处薄弱，每一点都不足以形成绝对优势，结果是"为敌所制"，一路滑到被迫转移。
- **结论**: 不是勇气不够，是兵力分配方式错了。
- **结果**: 原书明确将此归为"军事平均主义"的错误；具体兵力数字部分给出。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 小团队面对大公司/大预算对手，正面竞争没有胜算。
2. 手上只有 3–5 个人，却被要求同时做多个方向。
3. 已经"全面铺开"，但每个方向都只做到 60%，没有一个能交付。
4. 打赢了一场局部战役，却不知道是否该乘胜扩大战线。
5. 需要在资源评审中解释"为什么只做一个"。

### 语言信号 (用户的话里出现这些就应激活)

- "我们人手不够但还是全都想推" / "we're spread too thin"
- "先做透一个" / "nail one thing"
- "打歼灭战" / "focus fire"
- "以战养战" / "fund the next round from this one"
- "同时开工" / "run them in parallel"

### 与相邻 skill 的区分

- 与 `maoxuan-priority` 的区别：priority 判断"哪一个规定全局"，本 skill 决定"这一仗投多少、怎么算打完"；priority 是选择，concentrate 是配置。
- 与 `maoxuan-two-level` 的区别：two-level 判断"值不值得做"，本 skill 判断"第一仗怎么打"。
- 与"聚焦/Focus"口号的区别：本 skill 强制给出倍数、全歼标准与战后补给方式，而不只是"少做点"。

## E — 可执行步骤 (Execution)

**必需输入**：① 总体资源（人/钱/时间）与对手/约束的相对量级；② 候选目标清单（≥3 个）；③ 每个目标的防守强度与可交付边界。
**缺失时询问**：若无法估计"对手在某一点上的强度"，先做一轮小规模试探（可用 `maoxuan-investigate`），不要凭感觉定倍数。

**交付物与完成标准**：一份作战单——选定的唯一目标／投入倍数与绝对数／"打完"的判定标准／战后补给方式／放弃清单（明确不做什么）。

1. **承认总体劣势并写下来**
   - 完成标准：一句话说明"在总量上我们处于劣势/均势/优势"，附量级估计。
2. **列候选目标并标防守强度**
   - 完成标准：每个目标标注"对手投入、切换成本、可交付边界"三项。
3. **只选一个点**
   - 完成标准：明确排除其余目标，并写出排除理由（不是"以后再说"）。
4. **定倍数**
   - 完成标准：给出相对倍数（建议 ≥3 倍于该点的常规投入）与绝对人力/预算数字；若达不到倍数，缩小目标而不是加宽战线。
5. **定"全歼"标准**
   - 完成标准：写出"做到什么程度算完成、留下的半成品怎么处置"；不接受"完成 70% 也算过"。
6. **设战后补给**
   - 完成标准：写明这一仗能沉淀什么（组件、方法、客户、现金流）用于下一仗。
7. **打完再开下一仗**
   - 完成标准：在上一仗达到"全歼"标准前，不启动第二个主攻方向；如被强制启动，记录为风险。
8. **复盘选点质量**
   - 完成标准：结算时回答"当初判断该点较弱是否正确"，写进下一轮选点依据。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 存在必须同时守住的底线（合规、安全、核心客户维系）：这些不能用"暂时放弃地方"来处理。
- 对手可以在你集中兵力时直取你的要害（无纵深、无缓冲）：此时集中会导致后方失守，需先解决防护问题。
- 目标本身需要并行才能成立（如平台的双边冷启动）：应改用"两端同时最小化"的策略，而非单点全歼。

### 作者在书中警告的失败模式

- **平分兵力，处处攻击**（x19）：结果是每一点都不足。
- **以保守地方为主**：为守地而分散兵力，反而被各个击破。
- **打无准备无把握之仗**（p12）：未侦察、未集结就开打。
- **只击溃不歼灭**：对手恢复后卷土重来，自己得不到补充。

### 作者的盲点 / 时代局限

- 军事语境里的"全歼"有明确的敌我边界；商业语境中没有"歼灭"，对手会恢复、会转型。迁移时应把"全歼"改为"达到不可逆的交付状态"（如客户完成迁移、产品能力上线并被使用），而不是"打败对手"。
- "以战养战"在军事上成立（缴获），在商业上不总成立（前期投入常需外部资金）。需替换为"每一仗必须沉淀可复用资产"。
- 原文假定指挥者能自由选点；现实中选点常受政治与客户关系约束。遇到强行指定的目标，本 skill 只能用于"如何在该点上打出倍数"，不能解决"该不该打"。

### 容易混淆的邻近方法论

- 与"蓝海战略"不同：蓝海是换战场，本 skill 是在既定战场上选择打点。
- 与"最小可行产品"不同：MVP 求最快获得反馈，本 skill 求在一点上形成压倒性结果。
